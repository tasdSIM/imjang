# อิ่มจัง · Imjang

แอพเลี้ยงสัตว์นับแคลอรี่ (PWA ติดตั้งบนมือถือได้ ใช้งานออฟไลน์ได้)

**เปิดแอป:** https://tasdsim.github.io/imjang/ — push ขึ้น `main` แล้ว GitHub Pages จะอัปเดตเองภายใน 1–2 นาที

## รันบนเครื่อง
1. File > Open Folder เลือกโฟลเดอร์ `imjang`
2. รัน `npx serve .` ในเทอร์มินัล (หรือใช้ Live Server) แล้วเปิด URL ที่ได้
   — ห้ามดับเบิลคลิกเปิดไฟล์ตรงๆ เพราะ service worker ต้องใช้ http(s)

## ติดตั้งบนมือถือ
- ต้องเผยแพร่บน **HTTPS** (เช่น GitHub Pages, Netlify, Cloudflare Pages — อัปโหลดทั้งโฟลเดอร์ `imjang`)
- Android/Chrome: เปิดเว็บ > ตั้งค่า (เฟือง) > "เพิ่มไปหน้าจอหลัก" หรือเมนูเบราว์เซอร์ > ติดตั้งแอป
- iPhone/iPad: Safari > ปุ่มแชร์ > "เพิ่มไปยังหน้าจอโฮม"

## โครงสร้าง
- `index.html` โค้ดทั้งหมด (CSS, ข้อความไทย/อังกฤษ, ฐานอาหาร, สูตรคำนวณ `calcPlan`, หน้าจอต่างๆ, ส่วน PWA)
- `manifest.webmanifest` ข้อมูลแอปสำหรับติดตั้ง
- `sw.js` service worker: แคชหน้าแอป + รูปสัตว์ + ฟอนต์ ให้ใช้ออฟไลน์ได้
  **แก้ index.html แล้วให้เพิ่มเลข `VERSION` ใน sw.js** ผู้ใช้จะได้รับเวอร์ชันใหม่
- `bg/{sea,forest,stars}.svg` ฉากเพิ่มเติม (ห้องนอน `pet/room.webp` เป็นฉากเริ่มต้น) รายการฉาก ราคา และสีที่จางเข้าหา อยู่ใน `BGS`
  ซื้อและเลือกได้ในตู้เสื้อผ้า แท็บ "ฉาก" (`S.bg`, `S.bgOwned`) ภาพฉากจางลงด้วย CSS `.roombg` (opacity .55) ตัวละครจะได้เด่น
  จะเปลี่ยนเป็นรูปวาดก็ได้ แค่วางไฟล์ขนาด 900×738 แล้วแก้ `src` ใน `BGS`
- `icons/` ไอคอนแอป (สร้างจาก `pet/cat-1-happy.webp`)
- `pet/{species}-{stage}[-mood].webp` รูปสัตว์ 6 ชนิด (แมว หมา กระต่าย มังกร ลูกเจี๊ยบ ไดโนเสาร์) × 3 ช่วงวัย, `egg-*`, `wear-*`, `room.webp`
  รูปสัตว์มาจาก Coding Adventure (`src/art/pet`, 200×200) ท่า `-fat` = `{species}-overfed`
  ทุกช่วงวัยใช้รูปเดียวกัน ตัวจะใหญ่ขึ้นตามวัยด้วย `SC` ในโค้ด
  ข้อมูลเก่าที่เลือกหมีหรือจิ้งจอกไว้ จะถูกเปลี่ยนเป็นแมว (`normalize()`)

## ลำดับหน้าจอครั้งแรก (view ใน `render()`)
`intro` (3 สไลด์ ครั้งเดียว `S.introSeen`) → `welcome` เลือกสัตว์ → `hatch` ฟักไข่
→ `onb` คุยกับสัตว์ (ลำดับคำถามอยู่ใน `steps()`: ตั้งชื่อ เป้าหมาย เพศ อายุ ส่วนสูง/น้ำหนัก
สอน BMR น้ำหนักเป้าหมาย การขยับตัว สอน TDEE ความเร็ว สอนขาดดุล วันสำคัญ)
→ `plan` การ์ดแผน (สมการ ใช้ − ขาดดุล = กิน, วันที่ถึงเป้า) → `tut` ลองป้อน 3 มื้อ + ท่าอิ่มเกิน
→ `pledge` ลากตามรอยหัวใจ → `home`
- ทุกตัวเลขในหน้าสอนและการ์ดแผนมาจาก `calcPlan` / `bmrOf` เท่านั้น
- เลือกลดน้ำหนักได้ไม่ต่ำกว่า BMI 18.5 ถ้าน้ำหนักตอนนี้ต่ำกว่านั้น จะเตือนและเสนอให้รักษาน้ำหนักแทน
- "คำนวณแผนใหม่" ในตั้งค่าใช้ `onb` เดิม (ไม่ถามชื่อ) แล้วกลับหน้าหลักหลังการ์ดแผน

## หน้าหลัก
- แถบ 7 วัน (`weekStrip`) แตะวันก่อนหน้าเพื่อดูมื้อย้อนหลัง (`sheetDay`) เก็บข้อมูลไว้ 14 วัน (`rollover`)
- มื้ออาหารแบ่งเป็น เช้า/กลางวัน/เย็น/ของว่าง ทุกรายการเก็บ `m` (ช่วงมื้อ) และ `t` (เวลา)
  ชีตเพิ่มอาหารเลือกช่วงมื้อตามเวลาปัจจุบันให้อัตโนมัติ (`slotNow`)
- "กินบ่อย" (`quickList`) 6 รายการที่กินบ่อยที่สุดในช่วงที่เก็บไว้ แตะครั้งเดียวบันทึกได้เลย
- `FOODS` 210 เมนูใน 10 หมวด (ช่องที่ 9) รวมสินค้า 7-Eleven 23 รายการ (`s_*`) ตรวจกับ INMU, HDmall และตาราง Pantip/poeclub แล้ว
  ที่มาของแต่ละค่า และรายการที่แหล่งขัดกัน อยู่ใน [FOOD-SOURCES.md](FOOD-SOURCES.md)
- น้ำหนัก: `S.weights` [{d,w}] วันละ 1 ค่า, `S.prof.start` {d,w,rate} คือจุดเริ่มแผน (ใช้วาดเส้นแผนในกราฟ)
  บันทึกน้ำหนักแล้วจะคำนวณเป้าแคลอรี่ใหม่ (`saveWeight` → `planFor`) ถ้าถึงเป้าแล้ว ได้ +50 เหรียญ (ครั้งเดียว)
  และแผนจะเปลี่ยนเป็นกินเท่าที่ใช้ทันที จนกว่าผู้ใช้จะกดเปลี่ยนเป็นรักษาน้ำหนัก
- ตั้งค่า → "ทำไมเป้าเป็นเลขนี้?" เปิดการ์ดแผน (`rPlan`)

## ฟีเจอร์ที่ต้องเปิดผ่าน Claude Artifact
- ถ่ายรูปประเมินแคลอรี่ด้วย AI (`sample`) และซิงค์ข้ามเครื่อง (`db` + `user`)
  ทำงานเมื่อเปิดหน้านี้เป็น Claude Artifact เท่านั้น ในโหมด PWA ปุ่มถ่ายรูปจะปิดไว้
  และข้อมูลอยู่ใน localStorage ของเครื่อง (คีย์ `imjang.v1`)
- ในโหมด Artifact จะไม่ลงทะเบียน service worker และไม่แสดงปุ่มติดตั้ง
