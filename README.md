# อิ่มจัง · Imjang

แอพเลี้ยงสัตว์นับแคลอรี่ (PWA ติดตั้งบนมือถือได้ ใช้งานออฟไลน์ได้)

**เปิดแอป:** https://tasdsim.github.io/imjang/ — push ขึ้น `main` แล้ว GitHub Pages จะอัปเดตเองภายใน 1–2 นาที

## รันบนเครื่อง
1. File > Open Folder เลือกโฟลเดอร์ `imjang`
2. รัน `npx serve .` ในเทอร์มินัล (หรือใช้ Live Server) แล้วเปิด URL ที่ได้
   — ห้ามดับเบิลคลิกเปิดไฟล์ตรงๆ เพราะ service worker ต้องใช้ http(s)

## ติดตั้งบนมือถือ
- ต้องเผยแพร่บน **HTTPS** (เช่น GitHub Pages, Netlify, Cloudflare Pages — อัปโหลดทั้งโฟลเดอร์ `imjang`)
- Android/Chrome: เปิดเว็บ > ตั้งค่า (เฟือง) > "เพิ่มไปหน้าจอหลัก" หรือเมนูเบราว์เซอร์ > ติดตั้งแอป
- iPhone/iPad: Safari > ปุ่มแชร์ > "เพิ่มไปยังหน้าจอโฮม"

## โครงสร้าง
- `index.html` โค้ดทั้งหมด (CSS, ข้อความไทย/อังกฤษ, ฐานอาหาร, สูตรคำนวณ `calcPlan`, หน้าจอต่างๆ, ส่วน PWA)
- `manifest.webmanifest` ข้อมูลแอปสำหรับติดตั้ง
- `sw.js` service worker: แคชหน้าแอป + รูปสัตว์ + ฟอนต์ ให้ใช้ออฟไลน์ได้
  **แก้ index.html แล้วให้เพิ่มเลข `VERSION` ใน sw.js** ผู้ใช้จะได้รับเวอร์ชันใหม่
- `bg/{sea,forest,stars}.svg` ฉากเพิ่มเติม (ห้องนอน `pet/room.webp` เป็นฉากเริ่มต้น) รายการฉาก ราคา และสีที่จางเข้าหา อยู่ใน `BGS`
  ซื้อและเลือกได้ในตู้เสื้อผ้า แท็บ "ฉาก" (`S.bg`, `S.bgOwned`) ภาพฉากจางลงด้วย CSS `.roombg` (opacity .55) ตัวละครจะได้เด่น
  จะเปลี่ยนเป็นรูปวาดก็ได้ แค่วางไฟล์ขนาด 900×738 แล้วแก้ `src` ใน `BGS`
- `icons/` ไอคอนแอป วาดเป็นเวกเตอร์ใน `icons/icon.svg` (แมวโผล่จากชามข้าว) แก้ไฟล์นี้แล้วเรนเดอร์ใหม่เป็น PNG ทุกขนาด
  `icon-192/512` มุมโค้งในตัว, `icon-maskable-512` และ `apple-touch-icon` เต็มกรอบ (ระบบตัดมุมเอง) ตัวละครย่อ 88% ให้อยู่ในพื้นที่ปลอดภัย
- `pet/{species}-{stage}[-mood].webp` รูปสัตว์ 6 ชนิด (แมว หมา กระต่าย มังกร ลูกเจี๊ยบ ไดโนเสาร์) × 3 ช่วงวัย, `egg-*`, `wear-*`, `room.webp`
  รูปสัตว์มาจาก Coding Adventure (`src/art/pet`, 200×200) ท่า `-fat` = `{species}-overfed`
  ทุกช่วงวัยใช้รูปเดียวกัน ตัวจะใหญ่ขึ้นตามวัยด้วย `SC` ในโค้ด
  ข้อมูลเก่าที่เลือกหมีหรือจิ้งจอกไว้ จะถูกเปลี่ยนเป็นแมว (`normalize()`)

## ลำดับหน้าจอครั้งแรก (view ใน `render()`)
`intro` (3 สไลด์ ครั้งเดียว `S.introSeen`) → `welcome` เลือกสัตว์ → `hatch` ฟักไข่
→ `onb` คุยกับสัตว์ (ลำดับคำถามอยู่ใน `steps()`: ตั้งชื่อ เป้าหมาย เพศ อายุ ส่วนสูง/น้ำหนัก
สอน BMR น้ำหนักเป้าหมาย การขยับตัว สอน TDEE ความเร็ว สอนขาดดุล วันสำคัญ)
→ `plan` การ์ดแผน (สมการ ใช้ − ขาดดุล = กิน, วันที่ถึงเป้า) → `tut` ลองป้อน 3 มื้อ + ท่าอิ่มเกิน
→ `pledge` ลากตามรอยหัวใจ → `home`
- ทุกตัวเลขในหน้าสอนและการ์ดแผนมาจาก `calcPlan` / `bmrOf` เท่านั้น
- เลือกลดน้ำหนักได้ไม่ต่ำกว่า BMI 18.5 ถ้าน้ำหนักตอนนี้ต่ำกว่านั้น จะเตือนและเสนอให้รักษาน้ำหนักแทน
- "คำนวณแผนใหม่" ในตั้งค่าใช้ `onb` เดิม (ไม่ถามชื่อ) แล้วกลับหน้าหลักหลังการ์ดแผน

## หน้าหลัก
- แถบ 7 วัน (`weekStrip`) แตะวันก่อนหน้าเพื่อดูมื้อย้อนหลัง (`sheetDay`) เก็บข้อมูลไว้ 14 วัน (`rollover`)
- มื้ออาหารแบ่งเป็น เช้า/กลางวัน/เย็น/ของว่าง ทุกรายการเก็บ `m` (ช่วงมื้อ) และ `t` (เวลา)
  ชีตเพิ่มอาหารเลือกช่วงมื้อตามเวลาปัจจุบันให้อัตโนมัติ (`slotNow`)
- "กินบ่อย" (`quickList`) 6 รายการที่กินบ่อยที่สุดในช่วงที่เก็บไว้ แตะครั้งเดียวบันทึกได้เลย
- `FOODS` 287 เมนูใน 10 หมวด (รวมอาหารใต้/อีสาน/เหนือ ขนมไทย และผลไม้จากตารางกรมอนามัย) (ช่องที่ 9) รวมสินค้า 7-Eleven 23 รายการ (`s_*`) ตรวจกับ INMU, HDmall และตาราง Pantip/poeclub แล้ว
  ที่มาของแต่ละค่า และรายการที่แหล่งขัดกัน อยู่ใน [FOOD-SOURCES.md](FOOD-SOURCES.md)
- น้ำหนัก: `S.weights` [{d,w}] วันละ 1 ค่า, `S.prof.start` {d,w,rate} คือจุดเริ่มแผน (ใช้วาดเส้นแผนในกราฟ)
  บันทึกน้ำหนักแล้วจะคำนวณเป้าแคลอรี่ใหม่ (`saveWeight` → `planFor`) ถ้าถึงเป้าแล้ว ได้ +50 เหรียญ (ครั้งเดียว)
  และแผนจะเปลี่ยนเป็นกินเท่าที่ใช้ทันที จนกว่าผู้ใช้จะกดเปลี่ยนเป็นรักษาน้ำหนัก
- ตั้งค่า → "ทำไมเป้าเป็นเลขนี้?" เปิดการ์ดแผน (`rPlan`)
- เมนูของฉัน: กรอกเองแล้วใส่ชื่อ (ติ๊ก "เก็บไว้") จะเก็บใน `S.myFoods` [{id:'u_…',e,n,k,p,f,c}] สูงสุด 60 รายการ ชื่อซ้ำจะทับของเดิม
  แสดงเป็นหมวด `mine` ก่อนอาหารในตัว (`mineRows`, `allFoods`, `findFood`) ลบได้ในหมวดนี้ (แตะ ✕ สองครั้ง) รายการที่บันทึกไปแล้วไม่หาย
- ค้นหา (`searchFoods`) ไม่สนช่องว่างและตัวพิมพ์ ค้นทุกหมวด ชื่อที่ขึ้นต้นด้วยคำค้นอยู่ก่อน ปริมาณเลือกได้ ×0.5–×3

## น้ำ การขยับตัว ไฟต่อเนื่อง และการเตือน
- น้ำ: `S.water` {วัน: แก้ว} เป้า `waterGoal()` = 30 มล./กก. ÷ 250 มล. (6–12 แก้ว) แตะแก้วเพื่อตั้งจำนวน ครบเป้าครั้งแรกของวัน +5 เหรียญ (`S.bonus['w'+วัน]`)
- ขยับตัว: `S.moves` {วัน: [{a,min,k,t}]} กิจกรรมใน `ACTS` [emoji, MET] แคลอรี่ = (MET − 1) × น้ำหนักล่าสุด × ชั่วโมง (นับเฉพาะส่วนที่เกินจากนั่งเฉยๆ)
  บวกเข้าเป้าของวันนั้น (`goalOf(วัน)`) ใช้ทั้งการ์ดแคลอรี่ อารมณ์สัตว์ และแถบ 7 วัน บันทึกครั้งแรกของวัน +10 เหรียญ น้ำและขยับตัวเก็บ 14 วันเหมือนมื้ออาหาร
- ไฟต่อเนื่อง: แตะไฟมุมซ้ายบนดูรางวัล `MILES` (3/7/14/30/60/100 วัน) ได้เหรียญตอนไฟถึงวันนั้น (ใน `feed`) และขึ้นการ์ดฉลองถ้าไม่มีชีตอื่นเปิดอยู่
- เตือนในแอป: `S.remind` {on,b,l,d} ถ้าถึงเวลามื้อแล้ว (ภายใน 3 ชม.) และยังไม่บันทึกมื้อนั้น หน้าหลักจะขึ้นแถบเตือน (`dueSlot`, `nudge`)
  ถ้าเลยหกโมงเย็นแล้ววันนี้ยังไม่บันทึกและไฟ ≥ 2 วัน จะเตือนว่าไฟจะดับ
- เตือนตอนปิดแอป: แอปเว็บส่งแจ้งเตือนเองไม่ได้ (ไม่มีเซิร์ฟเวอร์) จึงสร้างไฟล์ปฏิทิน `imjang-reminders.ics` (`icsText`) 3 นัดรายวันตามเวลาที่ตั้ง มีเสียงเตือนตอนเริ่ม

## สำรองข้อมูล (เฉพาะโหมด PWA)
- ตั้งค่า → "สำรองข้อมูล": ส่งออกเป็น `imjang-backup-YYYY-MM-DD.json` รูปแบบ `{app:'imjang',v:1,at,data:S}`
  บน iPhone ใช้ share sheet (แอปที่ติดตั้งแล้วดาวน์โหลดไฟล์ไม่ได้) เครื่องอื่นดาวน์โหลดตรง `S.lastBackup` เก็บวันที่สำรองล่าสุด
- นำเข้าได้จากตั้งค่า หรือลิงก์ใต้ปุ่มเริ่มในหน้าเลือกสัตว์ (เครื่องใหม่ยังเข้าตั้งค่าไม่ได้) ต้องยืนยันก่อนแทนที่ (`readBackup`, `importBackup`)
- บันทึกมื้ออาหารเก็บไว้แค่ 14 วันเหมือนเดิม (`rollover`) ในโหมด Claude Artifact ไม่แสดง เพราะซิงค์ให้อยู่แล้ว

## บัญชีและซิงค์ (เซิร์ฟเวอร์ของแอปเอง)
แอปเปิดได้ 3 แบบ โค้ดหน้าเว็บชุดเดียวกัน:
| เปิดจาก | บัญชี/ซิงค์ |
|---|---|
| `imjang.cpxsim.online` (VM, `server/main.js`) | มี: สมัครด้วยชื่อ + รหัสผ่าน ข้อมูลซิงค์ข้ามเครื่อง |
| GitHub Pages | ย้ายบ้านแล้ว: พาไป `imjang.cpxsim.online` (ดูด้านล่าง) |
| Claude Artifact | ซิงค์ด้วยบัญชี Claude (`initSync`) |

- ลิงก์ GitHub Pages (`onOldHome`): ยังไม่มีข้อมูล หรือเคยย้ายแล้ว (`S.movedAt`) → ไปลิงก์ใหม่ทันที
  มีข้อมูล → หน้า "อิ่มจังย้ายบ้านแล้ว" (`rMoved`) ปุ่มย้ายจะแพ็กข้อมูลเป็น gzip + base64url ใส่ท้ายลิงก์ `#move=…` (ส่วนหลัง # ไม่ถูกส่งไปเซิร์ฟเวอร์)
  ลิงก์ใหม่อ่านแล้วถามยืนยันก่อนนำเข้า (`takeMove` → `importText`) และลบ `#move` ออกจากแถบที่อยู่ ข้อมูลในลิงก์เดิมไม่ถูกลบ
- หน้าเว็บถาม `api/ping` ตอนเปิด (`initAcct`) ถ้าตอบได้ (`SRV`) จะแสดงการ์ด "บัญชี" ในตั้งค่า และลิงก์เข้าสู่ระบบในหน้าเลือกสัตว์ บน `*.github.io` ไม่ถาม
- เซิร์ฟเวอร์: Node 24 ไม่มีแพ็กเกจเพิ่ม (`node:sqlite`) ไฟล์ `data/imjang.db` ตาราง `users`, `sessions`, `saves` (เก็บ `S` ทั้งก้อนเป็น JSON พร้อม `rev`)
  รหัสผ่านเก็บแบบ scrypt, token เก็บแค่ค่าแฮช, ลองเข้าสู่ระบบผิดได้ 20 ครั้ง/15 นาที/IP, เสิร์ฟเฉพาะไฟล์แอป (ไม่เสิร์ฟ `server/`, `deploy/`, `data/`)
- ซิงค์ (`acPush`, `acPull`): บันทึกแล้ว 1.5 วินาทีส่ง `PUT api/save {base: rev}` ถ้าเครื่องอื่นส่งก่อน เซิร์ฟเวอร์ตอบ 409 พร้อมชุดใหม่
  แล้วหน้าเว็บรวมกัน (`mergeSaves`: ใช้ชุดที่ใหม่กว่า แล้วเติมมื้ออาหาร น้ำ การขยับตัว น้ำหนัก และเมนูของฉันจากอีกชุด) ดึงใหม่เมื่อกลับมาเปิดแอปและเมื่อกลับมาออนไลน์
  ออฟไลน์ได้ตามเดิม ส่งเมื่อมีเน็ต `ACCT` ใน localStorage `imjang.acct` = {tok,name,rev,ts}
- เข้าสู่ระบบในเครื่องที่มีข้อมูลอยู่แล้วและบัญชีก็มีข้อมูล: ให้เลือกว่าจะใช้ชุดไหน (`acSignedIn`)
- ออกจากระบบ: ล้างข้อมูลในเครื่อง (ยังอยู่ในบัญชี) · ลบบัญชี: ต้องใส่รหัสผ่าน ลบบนเซิร์ฟเวอร์ทันที ข้อมูลในเครื่องยังอยู่
- ลืมรหัสผ่าน: ไม่มีอีเมล ผู้ดูแลตั้งรหัสชั่วคราวให้ `bash deploy/admin.sh` (ดูรายชื่อ) → `bash deploy/admin.sh u_xxx`
- สมัครต้องติ๊กยินยอม (อายุ 18+ และเก็บข้อมูลสุขภาพตาม PDPA) นโยบายอยู่ที่ `privacy.html` ถ้าเปลี่ยนสิ่งที่เก็บหรือระยะเวลาสำรอง ต้องแก้หน้านี้ด้วย

รันบนเครื่อง: `node server/main.js` แล้วเปิด http://localhost:8080 (ข้อมูลอยู่ใน `./data`) · ทดสอบ: `node test/server.js`

ขึ้น VM: `bash deploy/deploy-vm.sh` (commit ก่อน) ทำแบบเดียวกับแอปนักสืบ: สำรองฐานข้อมูล → คัดลอก → `docker compose -p imjang up -d --build` (ชุดทดสอบรันตอน build ถ้าไม่ผ่าน ตัวเดิมยังรันอยู่) → ตั้งสำรองทุกคืน 02:50 → เช็ก `/health`
- แยกจากแอปอื่นบน VM ทั้งหมด: `/opt/imjang`, project `imjang`, พอร์ต `127.0.0.1:8095`, tunnel ของตัวเอง (route `imjang.cpxsim.online` → `http://web:8080`)
- ครั้งแรกต้องมี `deploy/tunnel.env` (`TUNNEL_TOKEN=...` ห้าม commit) สคริปต์จะคัดลอกขึ้น VM ให้
- สำรอง: `/opt/imjang-backups` (ทุกคืนเก็บ 30, ก่อน deploy เก็บ 14, ไม่เกิน 30 วัน) ดึงลงเครื่อง `bash deploy/pull-backups.sh` วิธีกู้อยู่หัวไฟล์ `deploy/vm-backup.sh`

## ฟีเจอร์ที่ต้องเปิดผ่าน Claude Artifact
- ถ่ายรูปประเมินแคลอรี่ด้วย AI (`sample`) และซิงค์ข้ามเครื่อง (`db` + `user`)
  ทำงานเมื่อเปิดหน้านี้เป็น Claude Artifact เท่านั้น ในโหมด PWA ปุ่มถ่ายรูปจะปิดไว้
  และข้อมูลอยู่ใน localStorage ของเครื่อง (คีย์ `imjang.v1`)
- ในโหมด Artifact จะไม่ลงทะเบียน service worker และไม่แสดงปุ่มติดตั้ง
